# Requests for comments

An RFC is one proposal, written to be argued with. It compares the options side by side, counts the
cost, and lists the questions that are still open. A decision that an RFC produces is recorded as an
architecture decision record. The record points back to the RFC for the argument.

| ----------------------------------------------------- | -------------------------------------------------- | -------- |

Documents are numbered and never renumbered. Rejected and withdrawn records stay on disk as the
record of why a proposal was not taken.
